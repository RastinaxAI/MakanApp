# نتیجهٔ Issueها

`ERR-001` — Medium / backend / CONFIRMED / FIXED_LOCAL_VALIDATED_NOT_DEPLOYED

پاسخ‌های 404/405 خالی و 415 فریم‌ورک فاقد code پایدار هستند.

`ERR-002` — Medium / backend / CONFIRMED / FIXED_LOCAL_VALIDATED_NOT_DEPLOYED

RetryAfter موجود در Exceptionهای AI/Knowledge در خروجی HTTP حذف می‌شود.

`DEPLOY-001` — Medium / infrastructure / SUPPORTED / EXTERNAL_PENDING

قرارداد زنده با Working Tree یکسان نیست؛ deadline policy منتشر نشده است.

`RUNTIME-001` — High / unknown / UNKNOWN / AWAITING_OWNER_EVIDENCE

Root Cause تاریخی Deadline و Class 403/404 بدون Evidence SQL/Runtime هنوز قطعی نیست.

`CONTRACT-001` — Medium / frontend / CONFIRMED / HANDOFF_ONLY

پاسخ احراز هویت ناشناس BFF فقط status دارد؛ متفاوت از ProblemDetails مستقیم Backend است.
